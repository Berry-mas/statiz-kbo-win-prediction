# Statiz Public Dashboard

Compact Next.js dashboard for the Statiz dry-run MVP.

## Data Contract

The app reads `public/results.json`. That file is generated by the local Python
automation process and should contain finalized game results plus confirmed
submitted probabilities only.

Do not place API keys, raw Statiz API payloads, feature matrices, live schedules,
or unfinalized predictions in this directory.

## Local Commands

```bash
npm install
npm run dev
npm run build
npm run typecheck
```

For Vercel, set the project root directory to `web/`. No environment variables
are required.
