# Statiz Public Dashboard

Next.js dashboard for public Y-wins KBO forecast results and submission status.

## Data Contract

The app reads `public/results.json`. That file is generated by the Python
automation process and contains only public-safe submission summaries, finalized
game results, and model operating metrics.

Do not place API keys, raw Statiz API payloads, feature matrices, live schedules,
or unfinalized predictions in this directory.

## Local Commands

```bash
npm install
npm run dev
npm run build
npm run typecheck
```

For Vercel, set the project root directory to `web/`. The dashboard itself is
static. The optional manual submit API requires `MANUAL_SUBMIT_TOKEN`,
`GITHUB_ACTIONS_TRIGGER_TOKEN`, and related GitHub workflow environment values.
